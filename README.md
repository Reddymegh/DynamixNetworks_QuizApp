# 🎯 DynamixNetworks_QuizApp

This project is **Task-1** of my **Web Development Internship at Dynamix Networks**.  
It’s a fully interactive **Quiz Application** built using **HTML, CSS, and JavaScript**, allowing users to test their knowledge across multiple categories and difficulty levels.

---

## 🚀 Project Overview

The **Quiz App** provides a fun and engaging way to learn through questions from different topics and varying difficulty levels.  
Each session presents **5 random questions** with shuffled options, making every quiz attempt unique!

---

## 🧠 Features

✅ **Category Selection:**  
Choose between *Maths* and *Web Development* quizzes.

✅ **Difficulty Levels:**  
Select *Easy*, *Medium*, or *Hard* before starting the quiz.

✅ **Randomized Questions & Options:**  
Every attempt gives a new set of 5 random questions.

✅ **Instant Feedback:**  
- Correct option → turns **Green**  
- Incorrect options → turn **Red**  
This helps users learn immediately after each answer.

✅ **Score Display:**  
Final score shown at the end of the quiz.

✅ **Responsive White-Themed UI:**  
Clean, modern, and user-friendly design.

---
